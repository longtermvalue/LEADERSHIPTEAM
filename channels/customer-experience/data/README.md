# Customer-experience data — what goes where

Not sure? Drop it in the repo-root `inbox/` instead and run `/file-inbox`.

| Subfolder | Drop here | Typical source |
|---|---|---|
| `reviews/` | Review exports or pasted reviews | Google Business Profile, industry platforms |
| `surveys/` | NPS/CSAT/survey results | Survey tool export |
| `support-exports/` | Ticket exports, chat/email transcripts | Helpdesk → export |

After dropping: ask for a feedback analysis, churn review, or support audit.
