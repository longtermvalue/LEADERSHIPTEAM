# Legal data — what goes where

Not sure? Drop it in the repo-root `inbox/` instead and run `/file-inbox`.

| Subfolder | Drop here | Typical source |
|---|---|---|
| `contracts/` | Anything to review before signing + signed agreements (leases, MSAs, NDAs) | Email/deal folder |
| `corporate-records/` | Articles, by-laws, resolutions, registers, annual return confirmations | Minute book / lawyer |
| `insurance/` | Policies, certificates, renewal notices | Broker |

Drop a contract and run `/ask-counsel` or ask for a review before you sign.
Channel outputs are legal information, not legal advice.
