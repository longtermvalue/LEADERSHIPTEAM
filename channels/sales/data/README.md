# Sales data — what goes where

Not sure? Drop it in the repo-root `inbox/` instead and run `/file-inbox`.

| Subfolder | Drop here | Typical source |
|---|---|---|
| `crm-exports/` | Pipeline/deal CSVs (put the export date in the filename) | HubSpot/Pipedrive → export |
| `proposals/` | Sent proposals, quote templates | Your docs |
| `call-notes/` | Discovery/demo notes, transcripts | Notes app, call recorder |
| `pricing/` | Price list, discount policy | Wherever pricing lives |

After dropping a CRM export: ask for a pipeline analysis, win/loss review, or CRM
hygiene audit.
