# CEO data — what goes where

Not sure? Drop it in the repo-root `inbox/` instead and run `/file-inbox`.

| Subfolder | Drop here | Typical source |
|---|---|---|
| `board-minutes/` | Board/advisory meeting notes, prior board packs | Your records |
| `strategy-docs/` | Plans, vision docs, market research, prior annual plans | Your docs |
| `kpi-snapshots/` | Exported dashboards or metric snapshots | Any reporting tool |

Company-wide identity (profile, goals/OKRs, org chart) lives in `company/`, not
here. After dropping: `/weekly-brief`, `/exec-meeting`, or `/board-pack`.
