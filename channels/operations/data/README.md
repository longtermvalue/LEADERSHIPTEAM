# Operations data — what goes where

Not sure? Drop it in the repo-root `inbox/` instead and run `/file-inbox`.

| Subfolder | Drop here | Typical source |
|---|---|---|
| `sops/` | Existing process docs (finished SOPs live here too) | Your docs |
| `vendor-contracts/` | Vendor agreements, renewal notices, pricing schedules | Email/contract folder |
| `projects/` | Project plans, status notes, task exports | Asana/Trello/notes |
| `systems/` | Tool/system inventory, who-uses-what (shared with the Technology channel) | Start with a simple list |

Rough notes are fine — `ops-sop-writer` turns messy process descriptions into
clean SOPs.
