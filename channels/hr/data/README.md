# HR data — what goes where

Not sure? Drop it in the repo-root `inbox/` instead and run `/file-inbox`.
This folder holds confidential material — keep the repo private and tightly shared.

| Subfolder | Drop here | Typical source |
|---|---|---|
| `policies/` | Handbook, individual policies | Wherever they live today |
| `employment-agreements/` | Signed contracts, offer letters, contractor agreements | HR files |
| `payroll-reports/` | Payroll registers, T4 summaries, WSIB/EHT filings | Payroll provider reports |
| `recruiting/` | Role descriptions, postings, candidate notes | ATS / your docs |
| `training-records/` | OHSA awareness, WHMIS, AODA completion logs | Training provider |

After dropping: `/hr-compliance-check` for the audit, `/new-hire` when hiring.
