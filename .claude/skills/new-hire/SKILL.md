Build the complete hiring package for the role.

## Steps
1. **Define the role** with the user (compact questions, one round): the 12-month
   outcomes, must-haves vs. trainable, comp range (required for the posting —
   Ontario pay-transparency rules), FT/PT, location/remote, who it reports to.
   Check `hr-comp-analyst` reports for band guidance; check
   `company/goals-and-okrs.md` that the hire serves a goal (if it doesn't, say so).
2. **Affordability gate**: fully-loaded cost estimate (salary × ~1.12–1.15 for
   CPP/EI/EHT/WSIB + benefits if any) vs. the latest cash forecast — one paragraph,
   flag if tight, suggest `ceo-decision-memo` for a contested call.
3. **Produce the package** via the `hr-recruiter` method:
   - Job posting (compliant: comp range, AI-screening disclosure if applicable,
     accommodation statement, no protected-grounds content)
   - Interview kit: structured questions mapped to must-haves, work-sample task,
     anchored 1–4 scoring rubric, interviewer do-not-ask sheet
   - Offer-prep checklist (counsel-drafted termination clause note, signed-before-
     start rule)
4. **Onboarding plan** via the `hr-onboarding-offboarding` method: pre-day-1 through
   90 days including the mandatory Ontario week-1 items.
5. Save the pieces to `channels/hr/reports/drafts/` (posting, kit, onboarding as
   separate files) and reply with the posting inline + links to the rest.

## Rules
- No posting ships without a comp range — hold the line and explain why.
- The package ends with the professional-advice disclaimer (offer letters and
  termination clauses go through counsel).
